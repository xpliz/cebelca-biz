# 🐝 Čebelca.biz Themer

A modern, highly customizable dark mode theme & color customizer for **Čebelca.biz** (including login page, main app navigation, MooAccess popups, and financial data tables).

![Version](https://img.shields.io/badge/version-2.2.4-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Stylus](https://img.shields.io/badge/userstyle-Stylus-purple.svg)

---

## ✨ Features

- 🎨 **10 Hand-Crafted Theme Presets**: Seamlessly switch between popular developer color palettes (Dracula, Catppuccin, Tokyo Night, Nord, One Dark Pro, Gruvbox, and more).
- 🎛️ **Full Customization Pickers**: Change background colors, card headers, text colors, links, borders, and input fields using interactive browser color pickers.
- ⚡ **Live Theme Switching**: Built with CSS Custom Properties and Stylus preprocessor for instant live updates without reloading pages.
- 📱 **Complete UI Coverage**: Darkens main navigation tabs, date & time pickers, financial data tables, charts, forms, and dialog popups.

## 🚀 Installation

### Prerequisites
Install a UserCSS-compatible browser extension:
- **[Stylus](https://github.com/openstyles/stylus)** (Recommended):
  - [Chrome Web Store](https://chrome.google.com/webstore/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne)
  - [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/styl-us/)

### Installing the Style

1. Click on your **Stylus** extension icon in the browser toolbar.
2. Select **"Write style for: cebelca.biz"** or open the Stylus Manager -> **"Write new style"**.
3. Copy the entire contents of [`cebelca.user.css`](cebelca.user.css) into the editor.
4. Click **Save** (or `Ctrl + S`).
5. Open or refresh [cebelca.biz](https://cebelca.biz) to enjoy your new theme!

---

## 🎛️ How to Customize

1. Open the **Stylus** popup menu while on `cebelca.biz`.
2. Click the ⚙️ **Gear / Configure** icon next to **Čebelca.biz Themer**.
3. Choose your favorite preset from the **Theme Preset** dropdown list.
4. To create your own custom theme:
   - Select **Custom (Use Pickers Below)** from the dropdown.
   - Adjust the **Color Pickers** for Backgrounds, Cards, Text, Links, and Accents to your preference.
